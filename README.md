# Библиотека картинок

Картинки разложены по типам (не по проектам): фоны, наклейки, маскоты, иконки, паттерны, рамки...
Окно библиотеки (PyQt6) режет сгенерированные листы, раскладывает куски по разделам, ищет,
правит, сжимает и выгружает картинки в проекты.

Запуск: `Library.cmd`. Нужен Python 3.14 (`py -3.14`) с пакетами `PyQt6 pillow numpy`;
для поиска по смыслу ещё `onnxruntime`, для svg - `vtracer`, для страницы промптов - node.

## Как пользоваться

1. Взять промпт в `Prompts.html` (кнопки «Копировать» и «Имена»), сгенерировать картинку.
2. Положить её в `00 Входящие` или перетащить в окно (Ctrl+V тоже работает).
3. Во вкладке «Входящие» проверить нарезку и сохранить в раздел (Ctrl+S).
   Под полем «Метки» окно подсказывает метки по смыслу кусков («дракон, магия, милое») - щелчок добавляет.
   Файл с меткой в имени, например `Космос [ic tokyo]`, сам выбирает нарезку и папку.
4. Во вкладке «Библиотека» искать по имени, меткам, цвету или **по смыслу**
   (кнопка-шар, Ctrl+M: «кот в космосе», «уютная ночная улица»), сохранять поиски как **умные папки**.

Все горячие клавиши - F1 в окне. `Gallery.html` - вся библиотека в браузере (пересобирается сама).

## Устройство

```
00 Входящие/            неразобранное (в галерею и поиск не попадает)
01 Фоны/ ... 10 .../    разделы библиотеки; наборы - <раздел>/<набор>/<палитра>/
_sources/               исходные листы (<год-месяц>), оригиналы до сжатия и правки, _undone для Ctrl+Y
_tools/
  app.py                вход окна
  cli.py                командная строка: cut, convert, dupes, gallery
  imaging/              ядро без Qt (Pillow + numpy)
    files.py            пути, чтение с поворотом по EXIF, атомарная запись
    cutting.py          удаление фона, обводка, поиск рисунков на листе, нарезка сеткой
    encoding.py         форматы, размер, SSIM «на глаз», сжатие, svg
    editing.py          правка по рецепту (цвет + шаги), перекраска, кисть, тень
    similarity.py       отпечатки (дубли, «уже есть»), главные цвета
    clip.py             поиск по смыслу (CLIP через onnxruntime, русский и английский)
    doctor.py           проверка библиотеки
    sprites.py          атлас, svg-спрайт, значки программы, лист превью
    jobs.py             задачи для процессов по ядрам
    gallery.py          сборка Gallery.html и done.js
  ui/                   окно (PyQt6)
    main_window.py      главное окно, отмена/возврат, приём файлов, main()
    inbox_tab.py        вкладка «Входящие»
    library_tab.py      вкладка «Библиотека», быстрый просмотр, умные папки
    sorting.py          заготовки нарезки, метки в имени, запись в разделы
    prompts.py          данные Prompts.html (через node)
    db.py               SQLite: отпечатки, метки, заметки, умные папки, векторы CLIP
    signatures.py       индекс отпечатков; semantic.py - индекс поиска по смыслу; tagging.py - подсказка меток
    editor.py, compress.py, export.py, dupes.py, weight.py, doctor.py, missing.py - окна действий
    widgets.py, thumbnails.py, animations.py, theme.py, common.py - общее для окна
  tests/                unittest: run-tests.cmd или py -3.14 -m unittest discover -s tests
  cli/                  .cmd для перетаскивания файлов (нарезать, конвертировать, дубли)
  _models/clip/         модели поиска по смыслу (~225 МБ)
  _thumbs/              кэш миниатюр (можно удалить - пересоздастся)
  library.db            база; settings.json - настройки окна; _errors.log - ошибки окна
```

## Командная строка

```
py -3.14 _tools/cli.py cut лист.png --grid 4x3 --names a,b,c --outline 8
py -3.14 _tools/cli.py convert папка --to webp --max 1920
py -3.14 _tools/cli.py dupes
py -3.14 _tools/cli.py gallery
```

## Модели поиска по смыслу

- Картинки: CLIP ViT-B/32, квантованная ONNX-версия `Xenova/clip-vit-base-patch32` (vision_model_quantized).
- Текст: `sentence-transformers/clip-ViT-B-32-multilingual-v1` (ONNX quint8 + слой Dense) -
  понимает русский и ещё 50+ языков в том же пространстве, что и картинки.

Модели не лежат в репозитории (файлы больше 100 МБ): скачать - `py -3.14 _tools/get_models.py`.
Без папки `_tools/_models/clip` окно работает как раньше, кнопка поиска по смыслу просто скрыта.
