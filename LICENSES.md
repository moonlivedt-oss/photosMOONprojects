# Что под какой лицензией

**Русский** | [English](#english)

| Что | Лицензия |
|---|---|
| Код: папка `_tools`, `Library.cmd`, `Prompts.html` | MIT - см. [LICENSE](LICENSE) |
| Наборы Kenney (`04 Иконки/Kenney`, `08 Интерфейс/Kenney`, `10 Рамки и орнаменты/Kenney`) | CC0 1.0 - см. «_авторы и лицензия.txt» в папке набора |
| Hero Patterns (`07 Паттерны и текстуры/Hero Patterns`) | CC BY 4.0 - при публикации указать автора, см. «_авторы и лицензия.txt» в папке |
| Все остальные картинки библиотеки | принадлежат автору репозитория, все права защищены |

Лицензия MIT распространяется только на код. Картинки библиотеки под неё не попадают.

Ассеты Unreal (`_Unreal`) в репозиторий не входят: окно скачивает их само, и у каждого своя лицензия.
Она записана в `asset.json` ассета, а для проекта её собирает «Инструменты» -> «Авторы и лицензии проекта».
Почти всё - CC0; исключения: сканы Google Scanned Objects - CC BY 4.0 (указать автора: Google), часть моделей
Khronos - CC BY, модели NASA - общественное достояние без права на логотипы NASA, MetaHuman и Fab - лицензия Epic.

## English

| What | License |
|---|---|
| Code: the `_tools` folder, `Library.cmd`, `Prompts.html` | MIT - see [LICENSE](LICENSE) |
| Kenney sets (`04 Иконки/Kenney`, `08 Интерфейс/Kenney`, `10 Рамки и орнаменты/Kenney`) | CC0 1.0 - see "_авторы и лицензия.txt" in the set folder |
| Hero Patterns (`07 Паттерны и текстуры/Hero Patterns`) | CC BY 4.0 - attribution required, see "_авторы и лицензия.txt" in the folder |
| All other pictures of the library | belong to the repository author, all rights reserved |

The MIT license covers only the code. It does not cover the pictures of the library.

Unreal assets (`_Unreal`) are not part of the repository: the window downloads them, and each one has its own
license, recorded in its `asset.json`.
Almost all of them are CC0; exceptions: Google Scanned Objects scans - CC BY 4.0 (credit Google), some Khronos
models - CC BY, NASA models - public domain without rights to NASA insignia, MetaHuman and Fab - Epic license.
