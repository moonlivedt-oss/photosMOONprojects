# Участие в разработке

Спасибо за интерес к «Библиотеке картинок»! Код небольшой: ядро на Pillow и numpy, окно на PyQt6.

## Быстрый цикл

```bash
git clone https://github.com/moonlivedt-oss/photosMOONprojects.git
cd photosMOONprojects
py -3.14 -m pip install PyQt6 pillow numpy onnxruntime ruff
py -3.14 _tools/get_models.py        # по желанию: модели поиска по смыслу
Library.cmd                           # окно
cd _tools && py -3.14 -m ruff check . && py -3.14 -m unittest discover -s tests    # всё, что гоняет CI
```

## Как устроен код

| Папка | За что отвечает |
|---|---|
| `_tools/imaging/` | ядро **без Qt**: нарезка, кодирование и сжатие, правка, отпечатки, CLIP, доктор, атлас, галерея. Его зовут окно, `cli.py`, процессы по ядрам и тесты |
| `_tools/ui/` | окно: вкладки, диалоги действий, база (`db.py`), индексы отпечатков и смысла, подсказка меток |
| `_tools/tests/` | `unittest`; эталонные рамки настоящих листов из `_sources` - в `reference_boxes.json` |
| `_tools/cli/` | `.cmd` для перетаскивания файлов (окончания строк CRLF - иначе командная строка их ломает) |

- Тяжёлое (`imaging/jobs.py`, `job_*`) уходит в отдельные процессы: на входе и выходе - только
  путь, словарь настроек и байты.
- Из фонового потока в главный - только `ui.common.in_main(cb, value)`; фоновая задача - `bg(fn, cb)`.
  Длинные циклы проверяют `CLOSING`, иначе окно падает при закрытии во время загрузки.
- Исключение в слоте PyQt6 без `sys.excepthook` роняет процесс - главное окно ставит `install_guard`.
- Комментарий объясняет **почему** (подводный камень Qt, Pillow, Windows), а не пересказывает
  код; история правок - в CHANGELOG, не в коде.
- Видимый текст - по-русски, без эмодзи (код, интерфейс, Markdown, сообщения коммитов).
  Значки интерфейса берутся из самой библиотеки (`lib_icon(имя)` ищет в `04 Иконки`).

## Тесты

| Команда | Что проверяет |
|---|---|
| `_tools\run-tests.cmd` | все тесты: нарезка (сетка, слипшиеся соседи, автопоиск, рамки), правка, выгрузка, раскладка, промпты, база, метки, CLIP, эталонные листы |
| `py -3.14 -m unittest discover -s tests -k Cutting` | один класс тестов (из папки `_tools`) |
| `py -3.14 -m ruff check .` | линтер (`_tools/ruff.toml`) |

- Тесты окно не открывают. Проверить окно без показа можно скриптом с `w.grab()` по таймеру,
  подменив `ui.common.save_cfg` и `LOG`, чтобы не трогать настройки.
- Тесты CLIP пропускаются, если моделей нет (так и на CI).
- Нарезка изменилась осознанно - удалить `tests/reference_boxes.json` и прогнать тесты: эталон
  запишется заново.
